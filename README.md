# نظام إدارة الموارد البشرية | HR Management System

نظام Backend متكامل مبني بـ **Python 3 + FastAPI + SQLAlchemy (SQL)** لإدارة الهيكل الإداري بين
الإدارة والعاملين، يشمل:

- 🔐 نظام مصادقة وصلاحيات (JWT) بخمسة أدوار: **مدير، نائب مدير، محاسب، HR، موظف**
- 🕒 تسجيل ومتابعة **الحضور والانصراف**
- ⚠️ إدارة **الجزاءات والمكافآت**
- 💰 حساب **راتب كل موظف تلقائيًا آخر الشهر** (الأساسي + المكافآت − الجزاءات − خصم الغياب)

## ⚙️ التثبيت والتشغيل

### 1. إنشاء بيئة افتراضية وتثبيت المتطلبات

```bash
python3 -m venv venv
source venv/bin/activate      # على ويندوز: venv\Scripts\activate
pip install -r requirements.txt
```

### 2. إعداد متغيرات البيئة

```bash
cp .env.example .env
# عدّل القيم داخل .env حسب الحاجة (خصوصًا SECRET_KEY في بيئة الإنتاج)
```

### 3. تشغيل السيرفر

```bash
uvicorn app.main:app --reload
```

سيعمل التطبيق على: `http://127.0.0.1:8000`

- توثيق تفاعلي (Swagger UI): `http://127.0.0.1:8000/docs`
- توثيق بديل (ReDoc): `http://127.0.0.1:8000/redoc`

### 4. أول تسجيل دخول

عند أول تشغيل، ينشئ النظام تلقائيًا حساب **مدير** بالبيانات الموجودة في `.env`
(`FIRST_ADMIN_USERNAME` / `FIRST_ADMIN_PASSWORD`). استخدمه لتسجيل الدخول ثم أنشئ باقي
الحسابات (نائب مدير، محاسب، HR، موظفين) من خلال `POST /users/`.

⚠️ **مهم:** غيّر كلمة مرور حساب المدير الافتراضي فورًا في بيئة الإنتاج.

## 🧑‍💼 الأدوار والصلاحيات

| الدور | الصلاحيات |
|---|---|
| **المدير (manager)** | صلاحية كاملة على كل شيء: الموظفين، الحضور، الجزاءات/المكافآت، الرواتب |
| **نائب المدير (deputy_manager)** | نفس صلاحيات المدير تقريبًا، عدا إنشاء حسابات مدير/نائب مدير جديدة |
| **المحاسب (accountant)** | إدارة الجزاءات والمكافآت + حساب وعرض الرواتب |
| **الـ HR (hr)** | إدارة بيانات الموظفين + الحضور والانصراف + الجزاءات والمكافآت |
| **الموظف (employee)** | تسجيل حضوره/انصرافه فقط + عرض بياناته الشخصية (حضوره، جزاءاته/مكافآته، راتبه) |

الصلاحيات مطبّقة عبر `app/core/permissions.py` باستخدام FastAPI Dependencies،
بحيث كل Endpoint محمي حسب الدور المطلوب.

## 🔑 المصادقة (Authentication)

يستخدم النظام **JWT Bearer Token**:

1. `POST /auth/login` مع `username` و `password` (كـ form-data) → يُعيد `access_token`
2. أرسل التوكن في كل طلب لاحق داخل الهيدر:
   ```
   Authorization: Bearer <access_token>
   ```
3. `GET /auth/me` لعرض بيانات المستخدم الحالي

## 📌 أهم المسارات (Endpoints)

| الطريقة | المسار | الوصف |
|---|---|---|
| POST | `/auth/login` | تسجيل الدخول |
| GET | `/auth/me` | بيانات المستخدم الحالي |
| GET/POST | `/users/` | عرض/إنشاء موظفين |
| GET/PUT/DELETE | `/users/{id}` | عرض/تعديل/حذف موظف |
| POST | `/attendance/check-in` | تسجيل حضور اليوم (للمستخدم نفسه) |
| POST | `/attendance/check-out` | تسجيل انصراف اليوم (للمستخدم نفسه) |
| GET/POST | `/attendance/` | عرض/إضافة سجلات حضور (إداري) |
| PUT/DELETE | `/attendance/{id}` | تعديل/حذف سجل حضور |
| GET/POST | `/penalties-rewards/` | عرض/إضافة جزاء أو مكافأة |
| DELETE | `/penalties-rewards/{id}` | حذف سجل جزاء/مكافأة |
| POST | `/salary/generate` | حساب راتب موظف واحد لشهر معيّن |
| POST | `/salary/generate-all` | حساب رواتب كل الموظفين لشهر معيّن دفعة واحدة |
| GET | `/salary/` | عرض سجلات الرواتب |

القائمة الكاملة والتفاصيل الدقيقة لكل مسار (المدخلات والمخرجات) متاحة تلقائيًا على `/docs`.

## 💰 آلية حساب الراتب

يُحسب صافي الراتب الشهري للموظف كالتالي:

```
الراتب اليومي = الراتب الأساسي ÷ عدد أيام الشهر
خصم الغياب  = الراتب اليومي × عدد أيام الغياب المسجّلة في الشهر
صافي الراتب = الراتب الأساسي + إجمالي المكافآت − إجمالي الجزاءات − خصم الغياب
```

يتم استدعاء `POST /salary/generate-all` في نهاية كل شهر (يدويًا أو عبر مهمة مجدولة/Cron)
لحساب رواتب كل الموظفين النشطين دفعة واحدة.

## 🗄️ قاعدة البيانات

المشروع يستخدم **SQLite** افتراضيًا (ملف `hr_system.db` يُنشأ تلقائيًا) وهو مناسب للتطوير
والتجربة مباشرة بدون أي إعداد إضافي. للانتقال إلى **PostgreSQL** أو **MySQL** في الإنتاج،
غيّر فقط قيمة `DATABASE_URL` في `.env`، مثال لـ PostgreSQL:

```
DATABASE_URL=postgresql://user:password@localhost:5432/hr_system
```

(تأكد من تثبيت `psycopg2-binary` في حالة PostgreSQL أو `pymysql`/`mysqlclient` في حالة MySQL)

## 🛠️ التقنيات المستخدمة

- **FastAPI** – إطار العمل الأساسي للـ API
- **SQLAlchemy 2.0** – ORM للتعامل مع قاعدة البيانات
- **Pydantic v2** – التحقق من صحة البيانات
- **python-jose** – توليد وفك تشفير JWT
- **passlib[bcrypt]** – تشفير كلمات المرور
- **Uvicorn** – ASGI server
